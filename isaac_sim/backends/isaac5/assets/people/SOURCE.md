# Isaac5 local people asset bundle

This bundle is a minimal local runtime closure, copied on 2026-09-12 from the
locally installed Isaac Sim 6.0.1 data already present on this machine. It is
owned operationally by the Isaac5 backend only; it contains no link back to an
Isaac6 directory and no Isaac6 Python extension or executable.

Sources recorded before copying:

- Eight Character directories under `isaac_sim/assets-6.0.1/Assets/Isaac/6.0/Isaac/People/Characters/`.
- `stand_walk_loop_in_place.skelanim.usd` under the corresponding `People/Animations/` directory.
- `biped_demo_meters.usd` under the local replicator-agent cache data tree.
- `isaac_sim/isaacsim-6.0.1/LICENSE.txt`, copied verbatim into `licenses/`.

The local install supplies the NVIDIA Omniverse License, but this repository
does not contain a separate written redistribution permission for these assets.
Accordingly this is a local-use/versioned bundle, not evidence that publishing
or redistributing it is licensed. `SHA256SUMS` identifies the exact copied
files; the dependency audit named by `asset_manifest.json` is generated by
Isaac5's headless audit tool below the backend-local `generated/` directory.
