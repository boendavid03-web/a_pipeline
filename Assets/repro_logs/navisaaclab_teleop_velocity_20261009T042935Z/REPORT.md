# Nova Carter 指令速度与实际运动测量

## 执行条件

- 使用 A-fixed smoke 源码：`Assets/repro_logs/navisaaclab_tilt_motion_20261008T173940Z/source/`。启动前后源码文件哈希一致，且与 A/B/C smoke 的 `SOURCE_IDENTITY.json` 相符。

### 逐步异常与发生阶段

固定原地左转的 5 个角速度超限在控制步 61–65；前进左转的 8 个角速度超限在控制步 92–97、100、103。历史重放另有线速度超限 2 步、角速度超限 3 步，详见 `SUMMARY.json` 的完整 `step_outliers`。

超限主要发生在**根位姿写入后的物理步**：异常步的“写入前至根位姿写入”误差只有约 `0–11 µm/s` 和 `0–11 µrad/s`，而写入后物理位移/转角形成了测得误差。历史第 13 步的线速度误差为 `0.10313 m/s`，超出 `0.04999 m/s` 门槛；该步写入前误差仅 `0.000005 m/s`，物理步后偏移速度约 `0.10313 m/s`。轮目标速度可从 CSV/JSONL 查阅；轮实际速度也已记录。

历史步骤沿用先前结果的**零起始控制步编号**：

| 历史步 | 线误差 / 门槛 | 角误差 / 门槛 | 结论 |
|---:|---:|---:|---|
| 13 | 0.10313 / 0.04999 m/s | 0.03114 / 0.04591 rad/s | 线速异常复现；角速通过 |
| 16 | 0.02567 / 0.04999 m/s | 0.03027 / 0.04556 rad/s | 本次两项均通过，先前角速异常未复现 |
| 30 | 0.00554 / 0.01000 m/s | 0.04982 / 0.02000 rad/s | 角速异常复现 |
| 31 | 0.00673 / 0.01000 m/s | 0.02343 / 0.02769 rad/s | 本次两项均通过 |

控制量 `(v, ω)=(0,0)` 共 31 步；这些步仍有很小的位姿差分残动，线速度均值 `0.00044 m/s`、最大 `0.00780 m/s`，角速度绝对值最大 `0.00338 rad/s`。没有一步超过静止门槛。

整段均没有 `wall_blocked` 或 CrowdSim 碰撞标志。历史复现位置也没有墙体 guard 拦截信号。**未采集 PhysX 接触传感器/冲量**，所以这些软件标志不能证明没有物理接触。

## 判断

0.2、0.5、1.0 m/s 直行的平均实际前向速度分别为 `0.2015`、`0.4911`、`0.9914 m/s`，直行段全部逐步满足门槛。左右原地转弯实测约 `+0.4753` 与 `-0.4775 rad/s`；左转整段均值门槛虽过，5/15 单步未过。前进左转也出现 8/15 角速单步异常。机器人 7 的历史异常有部分重现，但不是完全复现：第 13、30 步异常再次出现，第 16、31 步本次通过。各偏差定位在位姿写入后的物理求解阶段；目前的遥测不能确定具体接触体或唯一原因。

同起点动作重放用于复核现象，不构成纯位置因素实验；本次只有单次重放，没有和“有静置预备段”做配对对照。

## GUI 手动控制

自动固定序列在非 headless GUI Isaac 进程中完成。本次没有人工按键输入。为当前 A-fixed 源码另存了 `RUN_WASD.sh` 和 `wasd_teleop.py`；在交互式终端运行：

```bash
bash Assets/repro_logs/navisaaclab_teleop_velocity_20261009T042935Z/RUN_WASD.sh --speed 0.2 --turn 0.5
```

把焦点留在该终端：`W` 前进、`A/D` 原地左/右转、`Q/E` 前进并转弯、`S` 或空格停止、`V` 重对准视角、`X` 退出。这个交互辅助脚本未在本轮第二次启动；本轮的正式测量仍是上面的固定重放。
