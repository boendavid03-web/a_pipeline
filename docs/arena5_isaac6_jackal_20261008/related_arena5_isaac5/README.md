# Related earlier Arena5 evidence (Isaac Sim 5.1)

These files are carried from the existing `a_pipeline` working tree as additional historical context. They describe separate Isaac Sim 5.1 / ROS 2 Humble investigations from 2026-10-01 and 2026-10-02. They are not evidence for the Arena Jazzy / Isaac Sim 6.0.0 results in the parent folder, and they must not be used to infer current Isaac 6 behavior.

Included: the uncommitted Arena5 reports, patches, and validation scripts present in the local `a_pipeline` worktree at publication time. Generated Python bytecode was omitted. The local checkpoint and ZIP artifacts were excluded. Paths and LAN addresses were redacted.
